# DÚO BAILA BAILA — Sitio Web Multipágina Interactivo

Proyecto web completo alineado a la línea gráfica del kit de juegos tradicionales de El Salvador **DÚO BAILA BAILA (Vol. 1: Trompo y Capirucho)**.

## Estructura de Archivos
- `index.html` — Página de inicio (Hero ilustrado, componentes de la caja cofre, productos destacados y colección Vol. 1–3).
- `tienda.html` — Catálogo interactivo con filtros por categoría, modal de vista rápida de especificaciones y aplicación de cupones.
- `academia.html` — Guía paso a paso (Trompo y Capirucho), cronómetro oficial para medir el "Dormilón", Bitácora interactiva de 4 Retos Pro y Certificado Maestro descargable/imprimible.
- `tradicion.html` — Historia cultural (Memoria · Identidad · Pertenencia) y formulario funcional de cotizaciones institucionales.
- `checkout.html` — Simulador completo de compra y pago (cálculo de envío por departamento de El Salvador, cupones `BAILA10` y `ELSALVADOR`, pago con tarjeta animada / QR / contra entrega, generación de comprobante e historial de pedidos).
- `css/styles.css` — Hoja de estilos unificada con paleta artesanal (`#F1DFC0`, `#542314`, `#E33B2B`, `#F6B61E`, `#1CA39E`) y texturas orgánicas.
- `js/app.js` — Lógica completa con persistencia en `localStorage`.

## Cómo abrirlo en Visual Studio Code
1. Descomprime la carpeta `duo-baila-baila-web` y ábrela en **Visual Studio Code**.
2. Haz clic derecho sobre `index.html` y selecciona **Open with Live Server** (o ábrelo directamente en tu navegador).
